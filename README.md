# 📝 Basic To-Do Web App

The Basic To-Do Web App is a simple task management web application created using HTML, CSS, and JavaScript.
It helps users organize their daily work by allowing them to add new tasks, view them in a list, and manage task completion easily.

The app separates tasks into two sections:

Pending Tasks → tasks that still need to be completed

Completed Tasks → tasks marked as finished

Users can also edit or delete tasks at any time. The app displays the date and time when a task is added and when it is completed to provide better task tracking.
# ✅ Features

Add new tasks instantly

Separate lists for Pending and Completed tasks

Mark tasks as Complete

Edit any task

Delete any task

Shows task Added time and Completed time

Clean & user-friendly interface

Works smoothly in any browser
